# El mundo de los gatos

Una pequeña página en español para conocer, cuidar y disfrutar a los gatos. Incluye una galería de imágenes y consejos básicos de cuidado.

## Publicación

El sitio se publica con GitHub Actions y GitHub Pages desde la rama `main`. Las imágenes se cargan desde Unsplash y requieren conexión a internet.

Cuando el primer despliegue termine, estará disponible en:

https://mirrayn.github.io/dasdadas/
